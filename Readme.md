


## SimpleTerm Commands


PMU

Here is a list of simpleterm commands and their possible replies:

* "reset": none
* "reset energy": "energy reset"
* "set address %lu": "address stored"
* "reset tamper": returns "reset tamper"
* "cal tamper": same
* "set tamper1 ofs %ld": same
* "set tamper2 ofs %ld": same
* "set tamper1 basis %ld": same
* "set tamper2 basis %ld": same
* "cal mode": same
* "normal mode": same
* "cal set v %ld": same
* "cal refine v %ld": same
* "cal set i %": same
* "cal set i ofs": same
* "set p limit %": same
* "set price %": same
* "set p limit %": same
* "turn relay on": same
* "turn relay off": same
* "rc config mode": same
* "rc send %3s": not sure

If command is not of the above format it returns "?"
