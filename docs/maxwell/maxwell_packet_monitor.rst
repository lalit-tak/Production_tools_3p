Maxwell Packet Monitor
======================

The maxwell-packet-monitor binary is used to read the packets being sent by the Maxwell board and print out the result on the screen.

.. code-block:: console

	usage: maxwell-packet-monitor [-h] [-d DEVICE] [-b BAUD]

	Allows to monitor the packets coming from maxwell board.Attach the FTDI cable
	to the Maxwell board and use this utility to monitor the packets sent by the
	Maxwell board.

	optional arguments:
	  -h, --help            show this help message and exit
	  -d DEVICE, --device DEVICE
	                        Device filename of the FTDI cable. Default is /dev/gp-
	                        gateway
	  -b BAUD, --baud BAUD  Baud rate to use to communicate with Maxwell board.
	                        Default is 2400


While using the maxwell-packet-monitor to read data from the Maxwell Board itself, the FTDI cable should directly be attached to the Maxwell board as shown in the picture below:

Reading Packets From maxwell-simulator
--------------------------------------

The Maxwell Packet monitor can be used to read any stream which is streaming valid Maxwell Packets. The most classical use of maxwell-packet-monitor is with the Maxwell board itself; but maxwell-packet-monitor can be used to look at the data being generated by maxwell-simulator as well. This small section helps you to do the same!

Step 1: Attach an FTDI cable to the computer (it may not be attached to anything. The FTDI cable is just being used to create a serial device such as /dev/ttyUSB0.)

Step 2: Run the Serial Sniffer binary

.. code-block:: console
	
	serial-sniffer /dev/ttyUSB0 -b 2400

Step 3: Run the Maxwell Simulator on the /tmp/dest port created by Serial Sniffer

.. code-block:: console

	maxwell-simulator -d /tmp/dest -b 2400

Step 4: Run the Maxwell Packet Monitor to read the values sent by the Maxwell Simulator itself. 

.. code-block:: console

	maxwell-packet-monitor -d /tmp/txdump -b 2400
